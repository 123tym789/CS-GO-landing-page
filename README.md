# CS:GO Landing Page
<img width="2550" height="1259" alt="image" src="https://github.com/user-attachments/assets/cba92fc1-e0e6-434e-b4d9-c1b27b37eed6" />

A modern, sleek, gaming-themed landing page for **Counter-Strike: Global Offensive (CS:GO)**.  
Built as a student project with pure HTML5, CSS3, and vanilla JavaScript.

---

## 🎯 Project Overview

This is an unofficial fan-made landing page designed to introduce visitors to CS:GO and provide a clear call-to-action to download the game.  

**Theme:** Dark mode with neon orange/blue accents, high-contrast typography, and an immersive esports vibe.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| **Sticky Navigation** | Logo, section links, glowing Download button, mobile hamburger menu |
| **Hero Section** | Particle effects, neon gradient text, stats, dual CTAs |
| **About Section** | Game overview + interactive **Accordion** (Competitive Mode, Economy, Bomb Defusal, Weapon Mechanics) |
| **Weapons Showcase** | Interactive **Carousel/Slider** with 5 iconic weapons, stats bars, auto-play, swipe & keyboard support |
| **Maps Section** | Responsive card grid (Dust II, Mirage, Inferno, Nuke) |
| **Screenshot Gallery** | Image grid with hover zoom + **Lightbox modal** |
| **Download CTA** | Prominent Steam download section |
| **Footer** | Quick links, social icons, disclaimer, copyright |
| **Responsive Design** | Fully optimized for mobile, tablet, and desktop |

## 🛠️ Technologies Used

- **HTML5** – Semantic markup
- **CSS3** – Custom properties (variables), Flexbox, Grid, animations, transitions
- **JavaScript (Vanilla)** – No frameworks or libraries
- **Google Fonts** – Orbitron (display) + Rajdhani (body)
- **Font Awesome 6** – Icons (via CDN)
- **Unsplash** – Placeholder images (via CDN)

---

## 🚀 How to Run

1. Download or clone the project files.
2. Open `index.html` in any modern web browser.
3. No build tools or installation required — it works offline (except external fonts/icons/images).

> **Note:** An internet connection is needed for Google Fonts, Font Awesome, and Unsplash images.

---

## 🎮 Interactive Components

### 1. Accordion (About Section)
- Click any header to expand/collapse content.
- Only one panel open at a time.

### 2. Weapons Carousel
- Previous / Next buttons
- Dot navigation
- Auto-play (pauses on hover)
- Keyboard arrows (← →)
- Touch swipe support on mobile

### 3. Gallery Lightbox
- Click any screenshot to open full-size view
- Previous / Next navigation
- Close with × button, Escape key, or backdrop click

### 4. Mobile Menu
- Hamburger icon toggles side navigation
- Closes automatically when a link is clicked

## 📱 Responsive Breakpoints

| Breakpoint | Layout Changes |
|------------|----------------|
| `≤ 992px` | About grid stacks, weapons become single column, maps stack, gallery 2 columns |
| `≤ 768px` | Mobile hamburger menu, reduced spacing |
| `≤ 576px` | Gallery becomes single column, buttons full-width |
